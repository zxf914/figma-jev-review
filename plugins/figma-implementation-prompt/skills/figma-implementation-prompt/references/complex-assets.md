# 复杂资源

## 资源保真门禁

先逐项盘点页面内的图片、插画、图标、纹理、复杂矢量、遮罩和其他非文本视觉节点。每项只能选择以下来源之一：

1. 项目中真实存在且视觉一致的资源。
2. 从 Figma 节点直接导出或从 Figma MCP 提供的资源地址下载的原资源。
3. 由真实数据驱动的项目地图或图表组件。
4. 用户明确授权的代码重绘。

只要 Figma 提供 image fill、image reference、导出设置、资源 URL 或可导出的矢量节点，就必须在提示词中要求实现者先导出或下载，再保存到经项目扫描确认的本地资源目录。页面代码必须引用该本地文件。

未经用户明确授权，禁止通过以下方式重新描摹或近似替代 Figma 已有视觉资源：

- 手写 `<svg>`、`path`、`polygon`、渐变、滤镜或矢量坐标
- 使用 CSS 渐变、阴影、伪元素、`clip-path` 或大量定位图形拼出原图
- 使用 Canvas 绘制、内联 Base64、占位图或近似的图标库图标
- 根据截图、节点名称、视觉复杂度或开发便利性自行重画

普通容器背景、边框、分隔线、纯色矩形或圆形等基础 UI 几何不视为图片重绘。真实地图、数据图表和明确需要动态变化的业务图形按项目组件实现，但不能借此重画其上的静态装饰资源。

无法取得原资源、导出结果不完整或无法确认资源边界时，必须列为阻塞项并生成草稿；不能把手绘 SVG 当作降级方案。

## 图层合成属性

资源文件只提供像素或矢量内容，Figma 图层负责它在页面中的最终视觉。对每个资源节点，从资源叶子向上检查直到页面容器，记录：

- 节点自身和父级的 `opacity`，以及图片填充自身的透明度；不能只读取图片文件的 Alpha 通道
- `blendMode`、背景混合、模糊、阴影、颜色调整和其他 effects
- 容器宽高、圆角、`clipsContent`、遮罩节点及遮罩边界
- 图片填充模式，如 fill、fit、crop、tile，以及裁切变换矩阵
- 资源在裁切容器内的实际宽高、缩放比例、X/Y 偏移和对齐方式
- 父子层级、叠放顺序、相对定位基准和是否继承父级透明度

区分三类透明度并标明作用位置：

1. 图层透明度应用在资源容器或图层节点上。
2. 填充透明度只应用于对应 fill。
3. 图片自身 Alpha 保留在原始文件中。

不能把图层透明度烘焙进下载文件，也不能因为下载的原图不透明就忽略 Figma 图层的透明度。存在多级透明度时，记录每一级原值和最终合成关系，不只写一个猜测后的结果值。

例如，图片外层为 `opacity: 30%`、容器启用裁切、图片在容器内放大并负偏移时，提示词必须分别写出 `30%`、裁切容器尺寸、内部图片尺寸或缩放比和 X/Y 偏移；禁止只写“使用该背景图片”。

截图只能用于验证最终观感，不能代替结构化图层属性。`get_design_context` 已返回 opacity、crop 或 transform 时使用其精确值；没有返回且视觉差异明显时，继续读取对应子节点。仍无法取得时列为待确认项。

## 决策顺序

1. 复用项目中视觉一致的现有资源。
2. 独立图标或装饰直接使用 Figma 导出的 SVG，并下载到项目本地。
3. 摄影、地图截图和纹理使用原始位图。
4. 多层资源共同构成单一静态视觉时合成为局部透明资源。
5. 文字、数值、选中状态、列表和交互区域保持动态渲染。
6. 真实地图或项目图表可以替代对应静态资源。
7. 动态性无法判断时询问。

Figma MCP 资源地址可能约七天后失效。提示词必须列出需要本地化的节点、格式、获取动作、建议文件名和项目资源目录；目录必须通过项目扫描确认。临时 URL 不能作为页面运行时地址。

## 局部合成

复杂插画不得因方便而把整个侧栏、页面或包含动态内容的区域导成一张图。应以一个稳定视觉对象为边界，例如设备、轨道、光束和箭头组成的上半部装饰。局部合成只能使用从 Figma 导出或下载的原始图层，不能把逐层手绘当作“拼接”。

合成时以父节点为局部坐标系：

```text
localX = childAbsoluteX - parentAbsoluteX
localY = childAbsoluteY - parentAbsoluteY
```

保持原图层顺序、裁切、镜像、旋转、图层透明度、填充透明度、混合、滤镜、遮罩和阴影。逐层拼接时固定设计画布，并整体缩放，不能让各子层分别响应式缩放。

## 动静分离

数量、单位、标题、状态、节点名称、结果列表和点击热区通常需要动态渲染。环形指标等复杂外观可以直接导出 SVG，动态数值与文字覆盖其上；只有图形本身确实随数据变化时才使用项目图表能力。

不得手绘、改写或近似重建 Figma 已有视觉资源。即使截图足够清楚、节点结构可读或手写看起来更快，也必须使用原始导出资源。只有用户明确授权代码重绘时，才能在提示词中采用该方案并标记为 `[用户已确认]`。

## 验收

提示词的验收清单必须检查：资源文件确实存在于约定本地路径；页面引用本地文件而不是 Figma 临时 URL；实现代码没有用手写 SVG、CSS 图形或 Canvas 替代清单中的原资源；每项资源的透明度、裁切、缩放、偏移、混合模式、滤镜、遮罩和层级与记录一致；动态文字和交互层仍可单独更新。需要把实现截图与 Figma 截图叠加或并排核对，重点检查半透明背景装饰是否过深、裁切区域是否错位。
