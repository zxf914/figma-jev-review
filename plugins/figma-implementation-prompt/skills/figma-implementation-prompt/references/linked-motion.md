# 联动状态与动效

## 单一状态源

多个区域展示同一业务对象时，提示词定义统一数据模型和稳定 ID：

```text
items       业务数据数组
activeId    当前业务 ID
activeIndex 当前索引
listOffset  列表轨道偏移
activePoint 地图坐标
phase       idle | exiting | entering | paused
```

卡片选中、列表位置、地图标签、箭头和落点都由当前项派生，不能使用互不关联的计时器更新。

## 轮播

用户明确“三秒切换”时可以记录三秒停留；仍需确认三秒从进入开始还是过渡结束后计算。默认第一项、下一项、最后循环到第一项只有在用户说明或项目已有规则时写为确定要求。

下列内容不能自行补全：

- 高亮沿可见列表移动，还是列表滚动并保持选中槽位固定
- 过渡持续时间、缓动、淡入淡出和地图平移方式
- hover、触摸、页面隐藏时是否暂停
- 手动点击后立即恢复、重新计时还是停止自动播放
- 数据刷新、删除当前项和排序变化后的选择规则

## 地图定位

真实地图使用经纬度和 SDK 投影；静态地图使用归一化坐标。指示箭头以尖端对齐点位。地图缩放、拖动或容器变化后重新计算覆盖物位置，靠近边缘时按已确认规则纠偏或翻转。

## 动效来源

`get_motion_context` 是 Figma 时间轴的事实来源。返回节点时记录精确关键帧、持续时间、缓动和时间线关系；返回空数组时，所有动效只能标为项目规范、用户描述或待确认，不能使用“Figma 动效”标签。

实现要求包含组件卸载和页面生命周期清理。Web 遵循 `prefers-reduced-motion`；App 使用项目已有的减少动态效果和生命周期机制。
