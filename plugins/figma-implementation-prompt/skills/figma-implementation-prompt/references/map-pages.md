# 地图页面

## 地图来源

先检查项目是否已有高德、百度或其他地图 SDK、初始化封装、坐标转换和覆盖物组件。已有真实地图时，Figma 静态底图只用于视觉参考，不下载为最终地图。没有地图能力时再说明静态地图或模拟方案。

记录地图容器、中心点、缩放级别、坐标系、可视边界、工具控件、图层和失败状态。Figma 没提供真实经纬度时，Mock 坐标必须标明来源。

## 点位与弹窗

点位数据至少区分业务 ID、经纬度或归一化坐标、名称、类型、风险等级、数量、选中状态和弹窗数据。数量徽标与图标分开渲染。

弹窗记录宽高、锚点、箭头尖端、关闭按钮热区、内部卡片、滚动区域和地图边缘避让。标题溢出、最大行数、Tooltip、点击展开和高度变化没有依据时询问。

## 面板与联动

地图与列表、详情或统计面板共享稳定业务 ID。点击任一区域后，其他区域由同一选中状态派生。

设计只展示三条记录不能证明最多三条，也不能证明超量后滚动。滚动、分页、轮播、展开或截断必须来自项目规范或用户确认。

## 隐藏和遮挡

`hidden` 只能证明 Figma 当前节点不可见。结合截图、坐标、父级裁切和覆盖面板判断它是遮挡、备用状态还是业务隐藏；无法确认时如实记录，不能据此删除图例或推导接口条件。
