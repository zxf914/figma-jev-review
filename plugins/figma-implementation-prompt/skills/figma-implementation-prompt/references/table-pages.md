# 表格页面

## 提取内容

记录表格总宽、表头和行高、每列宽度、内边距、对齐、固定列、分隔线、圆角、复选框、状态颜色、操作列和文本溢出。列宽不能在没有依据时改成平均分配。

Figma 只展示静态状态时，先查找项目中的 Table、Pagination、Radio、Checkbox、Select、Input、Dialog 和 Tooltip。找到后记录组件和样式文件；没有时按不确定项规则处理。

## Mock 数据

使用数组和列配置驱动表格。Mock 数据覆盖 Figma 出现的主要状态，并加入足以验证当前页面要求的长文本、空值和分页边界。字段名、类型、格式和示例值写入提示词。

不要固定生成 35 条、默认 10/20/50 条或自行决定跨页选择。数量和规则优先来自 Figma、项目或用户。

## 交互

根据原型入口和用户要求实现本地搜索、组合筛选、重置、分页、每页条数、添加、删除、详情、编辑、选择或全选。不能因为页面是表格就增加原型和需求中不存在的业务入口。

数据操作使用独立函数或项目 Mock 层，说明真实 API 替换位置。筛选结果决定分页总数；筛选或每页条数变化后的页码行为优先复用项目规范，找不到时询问。

删除确认、表单字段、校验、搜索触发方式、长文本、空状态和跨页选择会影响验收；没有依据时只能进入草稿。
