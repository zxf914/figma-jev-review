# Web 与 App 适配

## 平台识别

先从项目文件确认目标是 Web、React Native、Flutter、uni-app、Android、SwiftUI 或多端项目。多端共用一个 Figma 节点时，提示词分别列出平台实现差异；无法确定目标端时询问。

## Web

- 复用项目断点、布局容器和设计令牌。
- 固定格式大屏可以按基准画布整体缩放，但要说明缩放、留白和最小视口策略。
- 普通业务页面明确重排、最小宽度、横向滚动和文本溢出。
- 表格、地图、工具栏和固定面板使用稳定尺寸约束，避免内容变化引起布局跳动。
- 图标按钮保留项目规定的点击区域；动效遵循 `prefers-reduced-motion`。

## App

- 不能把 Figma px 无条件当成 dp、pt 或逻辑像素。优先采用项目现有换算和设计基准。
- 处理状态栏、刘海、灵动岛、底部手势区和安全区域。
- 按项目规则处理横竖屏、多设备比例、导航栈和返回手势。
- 表单说明键盘避让、焦点顺序和提交后的键盘行为。
- 长列表使用项目已有虚拟化组件，不渲染无限静态节点。
- 地图优先使用项目已有移动端 SDK；只有项目明确采用 WebView 时才复用 Web 地图。
- 页面进入后台、恢复和销毁时正确暂停或清理计时器、地图监听和动画。
- 图片按项目规则选择多倍图、SVG、PDF Vector 或平台资源目录，并检查字体打包授权。
- 在低性能设备和系统减少动态效果设置下提供项目一致的降级方式。

触控端没有 Web hover。任何依赖 hover 才能查看完整文本或暂停轮播的方案，都必须为触控端定义对应行为。
